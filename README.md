# Website Health Monitoring System

A Linux-based automated monitoring solution designed to perform sequential health checks on multiple websites. The system verifies reachability, checks HTTP response status, scans critical service ports, and logs monitoring results for analysis.

---

## Features
- Multi-website monitoring using configurable input file
- Reachability testing using Ping
- HTTP response status validation using Curl
- Port availability scanning (80, 443) using Nmap
- Structured logging of monitoring results
- Modular Bash scripting design for easy customization
